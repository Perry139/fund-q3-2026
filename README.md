## 页面结构

为保证首屏速度与移动端内存占用，页面拆为「列表元数据 + 正文分片」两部分：

- `index.html`（约 3.0 MB）：页面外壳与全部列表元数据，首屏即可检索、筛选、排序、查看规模与 Q3 收益率
- `d/p0.json … d/p12.json`（合计约 14.9 MB）：季报正文，按段落分片，后台并行渐进载入，右下角显示进度

正文做了**全局段落去重**：56,160 个段落去重为 28,808 个（省 48.7%），重复度最高的是同一模板下的固定小标题与一致的宏观市场回顾。

正文尚未到达的基金在展开时显示「载入中」，对应分片到位后自动回填，无需刷新。导出 CSV 若在载入完成前点击，会在载入完成后自动执行。
